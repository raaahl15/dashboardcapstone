# Panduan Penggunaan: Master_Instrument_Index_DME.csv

## 1. Aturan Penomoran Tag
- Digit Pertama (`1`, `2`, `3`): Menandakan Area Unit (Area 100: Dehidrasi & Reaksi, Area 200: Pemurnian DME, Area 300: Utilitas).
- Huruf Pertama: Besaran Ukur (`T` = Temperatur, `P` = Tekanan, `F` = Aliran, `L` = Ketinggian, `A` = Analisis Kimia).
- Huruf Berikutnya: Fungsi Instrumen (`I` = Indicator, `C` = Controller, `T` = Transmitter, `V` = Valve).
