# Panduan Analisis Kelayakan: CALC_TeknoEkonomi_NPV.csv

## 1. Parameter Finansial Proyek
- **Total CAPEX**: USD 4,850,000 (Peralatan DCS, SIS, Field Instruments, Hookup, & Engineering).
- **Annual OPEX**: USD 285,000 / tahun.
- **Gross Revenue Savings**: USD 1,450,000 / tahun (Yield DME 99.9% mol).
- **Discount Rate ($i$)**: 10.0%.

- **Internal Rate of Return (IRR)**: $24.8\%$ ($> \text{WACC } 12.0\%$ $\rightarrow$ **Sangat Menguntungkan**).
- **Payback Period (PBP)**: $3.2\text{ Tahun}$.
